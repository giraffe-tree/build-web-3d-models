# Premium ergonomic task chair：独立盲评

> Historical A/B comparison against the old blockout. Its B evidence predates the final UI-free recapture, so it is not the authoritative final decision. See `independent-critic-exact.md` and the bound hashes in `quality-evidence.json` for the current 73/100 `partial` verdict.

## 评审边界

本评审只依据原始请求与指定的 6 张渲染图进行。没有读取实现代码、项目 brief、manifest、自评分、review、性能数据或其他项目文件。评分反映的是像素中可见的完成度与证据强度；没有提交的视角或运动证据按 **missing evidence** 处理，不推定通过。静止 rest state 是主要目标，因此“没有持续动画”本身不扣分，但“允许绕看”的可用性仍需证据。

## 候选 A

### 像素识别

画面呈现一把青绿色/黑色的网背办公椅，放在深蓝黑技术演示页中。矩形网背、浅色腰靠、厚坐垫、两侧扶手、气压柱与五星脚使对象身份清楚；整体气质偏低多边形科技原型，而不是近距离可信的 premium 产品英雄资产。

### 五个最大可见缺陷（按影响排序）

1. **宏观形体仍过于通用且玩具化。** 坐垫是厚而方的圆角块，靠背近乎平直矩形，扶手和五星脚均是粗略基础形；虽能读成办公椅，却没有足够独特、精确的工学轮廓来支撑“premium ergonomic task chair”。
2. **承力与调节构造不清。** 亮色腰靠像贴在网面前的悬浮条；扶手柱、靠背下端、座壳、倾仰机构和气压柱之间缺少可读的连续载荷路径。脚轮的叉架、转轴与脚端连接也过度简化。
3. **材质响应扁平且分离不足。** 坐垫、扶手、框架主要依赖颜色区分，缺少织物、软垫、涂层金属、塑料和橡胶各自不同的高光宽度与粗糙度。底部黑色结构被暗部吞没，网背更像带规则线条的半透明平板。
4. **近景所需的表面完成度缺失。** 看不到可信的织物密度、缝线、包边、模缝、紧固件、控制器细节、边缘微倒角或微小粗糙度变化；现有网格线机械且均匀，没有受力、张紧或深度感。
5. **证据覆盖不足，页面也没有把模型当作真正的近景 hero。** 只提交了一张固定三分之四视图；后视、侧视、中性光、掠射光、细节近景和实际绕看过程全部缺失。模型在被左侧实验导航、标题和性能 HUD 分割的画面中占比有限；“Motion on”和操作提示只是文字，不能证明运动或交互有效。

### 身份关键特征审计

- **薄弱：** 人体工学背部曲率、可调腰托、坐垫前缘/瀑布边、扶手调节语义、同步倾仰机构、座深/座高控制。
- **脱离或不可置信：** 腰靠与网面/框架的固定关系不明；扶手与座壳、脚轮与五星脚的机械连接过于抽象。
- **缺失证据：** 侧面 S 曲线、靠背后支架、座底机构、脚轮叉架、绕看、缩放和任何有益运动。
- **裁切/UI：** 主体本身未被明显裁切，也未被 UI 直接遮挡；问题是左侧栏和 HUD 占据大量视觉预算，使椅子不够接近 hero 尺度。

### Finish defect 与有意 stylization

- **可视为有意 stylization：** 青绿色单色体系、圆角低多边形语言、规则网格、深色技术实验室氛围；不应仅因它不写实而扣分。
- **真正的 finish defect：** 部件连接与承力逻辑含混、材质响应同质化、脚轮与座底机构过简、暗部吞形、缺少近景层级，以及无法由提交证据验证绕看。这些问题会在任何风格下削弱可信度。

### 最高价值改动

重做一套**从靠背/腰托，经座底倾仰机构，到气压柱与五星脚的连续可读承力系统**，同时让该系统在三分之四 hero 中显露关键连接。它会一次性提升工学身份、比例层级、机械可信度和高端产品感。

**Status：blockout**

## 候选 B

### 像素识别

画面呈现一把深石墨色、暖铜色与浅灰织物组合的高背任务椅。巨大的椭圆背框、Y 形后支撑、软垫扶手、双层座体、气压柱和五星脚形成鲜明识别；暗色摄影棚、暖冷边光与编辑式排版带来高端概念产品气氛。它明显比 A 更接近 polished-stylized 成品，但仍有“雕塑化展示椅”强于“可信工学任务椅”的倾向。

### 五个最大可见缺陷（按影响排序）

1. **椭圆靠背的雕塑身份压过工学身份。** 正面轮廓强而优雅，但背面几乎是平滑大椭圆，侧向 S 曲线、肩胛释压、明确腰区和张力分区都不够可读；浅而窄的坐垫与高大靠背组合也让人体支撑比例略显头重脚轻。
2. **五星脚与脚轮构造仍不够可信。** 多个轮子像直接接在腿端的单片圆盘，叉架、水平转轴和竖直旋转轴的层级不足；不同角度下脚轮形态显得不一致，部分脚端/轮组有悬浮或脆弱感。相对上方大靠背，底座展开半径也略显保守。
3. **背板的光学与材质身份不稳定。** 正面图中它是带雾化透光的棕灰薄膜，背面图中又更像深蓝黑实心板；没有足够织纹、孔隙、张力或边缘夹持细节来证明其为柔性承托材料，局部更接近烟熏玻璃或软焦塑料。
4. **座椅核心连接与控制语义仍有含混。** 座垫、前横杆和下壳像数层圆角体叠放，缺少明确压合、包覆或紧固关系；外侧支杆、铜色大圆关节与细控制杆虽然有造型感，却未清楚表达哪个部件绕哪个轴工作。靠背下框、扶手支柱与座体附近也出现多处近切/汇聚，载荷路径不够一眼可读。
5. **证据与展示仍有最后一公里问题。** `orbit-a` 中主体偏小且背部融入暗背景；中性光页的大量小字和导航对比度过低；`subject-proof` 的近景有意裁掉背框顶部、部分扶手和多数脚轮，适合看材质但不能验证完整身份。两张 orbit 静帧证明多角度状态存在，却没有实际拖拽/缩放过程或连续状态证据；严格说交互仍未完全验证，且缺真正侧面轮廓。

### 分项评分

| 类别 | 得分 | 判断 |
|---|---:|---|
| silhouette / proportion | **20/25** | 轮廓独特、重心清楚、主次体块成熟；椭圆背与浅座的工学比例仍有疑问。 |
| construction / attachment | **14/20** | 前后结构和主要节点可见，但脚轮、座体叠层、关节/控制器语义不够落实。 |
| material / light response | **16/20** | 石墨、铜和织物有较好分离，暖冷光塑形有效；背板响应不一致，黑材质局部偏塑料化。 |
| surface detail / variation | **9/15** | 坐垫近景有织纹与细微变化，但背板、金属、接缝和硬件仍显光滑/稀疏。 |

| **总分** | **74/100** |  |

### 身份关键特征审计

- **薄弱：** 可读的腰部调节、背部纵向曲率、座深调节、扶手多向调节、同步倾仰关系，以及脚轮的真实万向叉架。
- **存在但含混：** 后部 Y 形支撑、右侧铜色圆关节/控制杆、扶手支柱、座下壳体；它们增加了机械语言，却没有完全说明功能与连接。
- **不可置信：** 若将背板理解为织物/网面，其正反面响应与边缘夹持不足；若理解为硬壳，其雾化透光又不自然。部分轮组的安装和接地也欠可信。
- **缺失证据：** 严格侧视、背部掠射近景、脚轮/座底近景，以及实际拖拽与缩放的连续交互证据。
- **裁切/UI：** hero、orbit 与 neutral 的主体没有被 UI 遮挡。`subject-proof` 对顶部靠背、扶手边缘和底部轮组的裁切是有意细节构图，但不能充当整椅验证图；页面小字未遮物，却在亮色中性页上接近不可读。

### Finish defect 与有意 stylization

- **可视为有意 stylization：** 椭圆背框、夸张圆角、暖铜细线、低饱和石墨配色、戏剧性长投影和杂志式留白。它们共同建立了稳定而高级的视觉语言，不应因非传统工业造型被自动判错。
- **真正的 finish defect：** 工学曲率证据薄弱、脚轮叉架/连接不成立、背板材质前后不一致、座体叠层与控制器功能含混、极低对比小字，以及交互与侧视证据缺失。风格化可以简化零件，但不能让承力、接地或材料类别失去可读性。

### 最高价值改动

把椭圆靠背升级为一套**具有明确侧向 S 曲线、可读腰部张力区，并通过 Y 形支撑连续连接到座底关节的完整工学系统**；随后用严格侧视和后侧近景证明。保留椭圆签名轮廓，但让它从装饰性图形变成可信的身体支撑结构。

**Status：partial**

## A/B 结论

- **A：37/100 — blockout**
- **B：74/100 — partial**
- **B 相比 A 的净提升：+37/100**
- **置信度：0.84（中高）**。对像素中可见的造型、材质、构造和页面呈现判断置信度高；总对比置信度略受证据不对称影响——A 只有一张 hero，而 B 有五张固定视图。缺证没有被当作通过，B 的固定多视图也没有被当作完整交互证明。
